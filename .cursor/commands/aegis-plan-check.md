# /aegis-plan-check

Verify that the current work is still aligned with the AEGIS planning document.

## Steps
1. Identify the current module or task.
2. Map it to a specific planning requirement or section.
3. Detect deviations, ambiguities, or missing assumptions.
4. Report whether the work should continue or pause for clarification.
5. Keep the report concise and traceable.
6. Use this before any new module is added or any architectural deviation is proposed.
