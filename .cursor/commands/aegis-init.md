# /aegis-init

Initialize the AEGIS-NERVE MVP runtime.

Use when you want to bootstrap the shared memory IPC layer, schema registry, memory store, and SAC anchor.

## Steps
1. Read the crystallized docs relevant to the nerve, SAC, and memory.
2. Validate the current schema and project layout.
3. Scaffold or refresh the Rust core interfaces.
4. Run the minimum test suite for IPC and schema validation.
5. Report readiness blockers.
