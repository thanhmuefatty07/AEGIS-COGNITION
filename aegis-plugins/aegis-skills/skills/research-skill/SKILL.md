# Research Skill

## Overview
Research is a pipeline: decompose, retrieve, cross-check, bind evidence, and
summarize only supported claims.

## When to Use
Use for broad or current questions, competitor analysis, and source-backed design.

## Core Concepts
Separate candidates from facts. Prefer primary sources and implementation files.

## Examples
Search official docs, inspect source, then write an architecture note with test
targets.

## Best Practices
Track source URL, retrieval time, artifact hash, and confidence.

## Common Pitfalls
Do not use README claims when source code is available.
