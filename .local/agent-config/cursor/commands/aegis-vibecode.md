# /aegis-vibecode

Run a high-throughput vibecoding block with minimal context churn.

## Steps
1. Identify the single active objective.
2. Batch related tasks into one coherent block.
3. Delegate deep specialization to the appropriate skill or subagent.
4. Record only a meaningful checkpoint at the end of the block.
5. Report next action, drift risks, and resume instructions.
6. Prefer durable summaries over repeated context restatement.
