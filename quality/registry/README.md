# AESE evidence registry

`current_inventory.json` is the Phase 0 inventory for the AEGIS Adaptive
Evidence & Simulation Engine (AESE). It is generated by
`scripts/aese_inventory.py` from tracked tests, benchmarks, fuzz targets,
scripts and hosted workflows.

`current_claim_graph.json` is the AESE-1 shadow graph generated by
`scripts/aese_claim_graph.py` from the inventory and the canonical GT96 and
not-verified registries. It describes source-backed claim, contract,
invariant, verification and future-obligation relationships; it cannot select,
skip, promote or delete evidence while `AESE_MODE=SHADOW`.

The registry is intentionally conservative:

- every discovered item receives exactly one migration disposition;
- existing runners remain `RETAIN_UNCHANGED` until shadow evidence proves a
  stronger wrapper or replacement;
- unmapped claim, owner, cost, platform and failure fields stay `UNKNOWN`;
- an inventory is not a test result and cannot promote a claim;
- direct cutover and deletion remain prohibited until the directive's
  supersession and rollback gates pass.

Run the bounded generator with:

```text
.venv\\Scripts\\python.exe scripts\\aese_inventory.py
```

The bounded drift check used by local/CI validation is:

```text
.venv\\Scripts\\python.exe scripts\\aese_inventory.py --check
```

The shadow graph drift check is:

```text
.venv\\Scripts\\python.exe scripts\\aese_claim_graph.py --check
```
